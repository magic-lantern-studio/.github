# Contributing to Magic Lantern Studio Projects

Thank you for considering contributing to Magic Lantern Studio! We welcome all contributions, from bug reports and documentation updates to new features.

## How You Can Contribute

### Reporting Bugs
Before creating a bug report, please check the existing issues to avoid duplicates. When creating a bug report, include as many details as possible:
* **Clear title and description** of the problem.
* **Steps to reproduce** the behavior.
* **Expected vs. actual behavior** (screenshots or error logs are very helpful).
* **Environment details** (OS, browser, runtime version, etc.).

### Suggesting Enhancements
Feature requests and improvements are always welcome. Open an issue and provide:
* A clear summary of the proposed feature.
* The problem it solves or the use case it supports.

### Submitting Pull Requests
1. **Fork the repository** and create a new branch from `main` or `master` (e.g., `git checkout -b fix/issue-description` or `feat/new-feature`).
2. **Set up your environment** and install dependencies (see `README.md` for instructions).
3. **Make your changes**, keeping your commits small, focused, and easy to understand.
4. **Test your changes** to ensure existing tests pass and add new tests if applicable.
5. **Follow the project's coding style** and linting rules.
6. **Open a Pull Request** against the `main` or `master` branch with a clear description of what you changed and why.

## Code of Conduct
Please be respectful and constructive in all interactions. By participating in this project, you agree to abide by our CODE_OF_CONDUCT.md.

## Questions?
If you have questions or need help getting started, feel free to open a discussion or reach out via [Issues](../../issues).
